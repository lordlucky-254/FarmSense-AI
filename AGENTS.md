# Instructions for coding agents

- Present outputs as decision support; identify their source and uncertainty, and require local verification.
- Never prescribe pesticides, antibiotics, or dosages. Escalate urgent crop and animal-health concerns to qualified local professionals.
- Clearly distinguish user-provided observations from external weather/model data; do not imply a provider is integrated when it is not.
- Run `python -m pytest -q` from the repository root after backend changes.
- Keep credentials, personal farm data, and unlicensed datasets out of Git.
